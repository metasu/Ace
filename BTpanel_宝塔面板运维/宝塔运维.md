## 一、安装与卸载

### 1.1 安装 wget 工具

Ubuntu / Debian：

```
apt-get install wget
```

CentOS：

```
yum install -y wget
```

### 1.2 专业版安装命令

CentOS：

```
yum install -y wget && wget -O install.sh http://download.bt.sy/install/install_6.0.sh && sh install.sh
```

Ubuntu / Deepin：

```
wget -O install.sh http://download.bt.sy/install/install-ubuntu_6.0.sh && sudo bash install.sh
```

Debian：

```
wget -O install.sh http://download.bt.sy/install/install-ubuntu_6.0.sh && bash install.sh
```

Fedora：

```
wget -O install.sh http://download.bt.sy/install/install_6.0.sh && bash install.sh
```

### 1.3 升级命令

Linux 面板 7.7.0 升级专业版：

```
curl http://download.bt.cn/install/update6.sh|bash
```

升级到 7.6.0 纯净版（未测试）：

```
curl http://v7.hostcli.com/install/update6.sh|bash
```

### 1.4 卸载命令

```
wget http://download.bt.cn/install/bt-uninstall.sh
sh bt-uninstall.sh
```

## 二、SSL 证书申请报错排查

### 2.1 报错：`module 'OpenSSL.crypto' has no attribute 'sign'`

运行以下命令，然后重启宝塔面板：

```
btpip install pyOpenSSL==24.2.1 -U
```

### 2.2 报错：`(ERROR SSL) Invalid version. The only valid version for X509Req is 0.`（509 错误）

此错误通常由不兼容的 OpenSSL 版本导致。两种解决方案：

**方案一：修改源码**

编辑 `/www/server/panel/class/acme_v2.py`，将 `X509Req.set_version(2)` 改为 `X509Req.set_version(0)`，然后重启面板。

**方案二：降级 pyOpenSSL**

```
btpip install pyOpenSSL==22.1.0
btpip install cffi==1.14
bt 1
```

## 三、中文乱码解决

来源：https://vpsxb.net/2187/

### 3.1 CentOS / RHEL

```
vi /etc/locale.conf
LANG="en_US.UTF-8"
```

### 3.2 Ubuntu / Debian

```
apt install locales
dpkg-reconfigure locales
```

在语言选择界面用方向键移动，按空格勾选：

- `en_US.UTF8`
- `zh_CN GB2312`
- `zh_CN GBK GBK`
- `zh_CN UTF-8 UTF-8`

勾选后按 Tab 切换到 OK，回车确认。在默认语言界面选择 `en_US.UTF8`，Tab 切换到 OK，回车确认。

```
vi /etc/default/locale
LANG=en_US.UTF-8
```

然后重启系统：

```
reboot
```

## 四、数据库相关

### 4.1 MySQL 进程守护

登陆宝塔面板后台 → 计划任务：

- 任务类型：Shell 脚本
- 任务名称：Mysql 进程守护
- 执行周期：每 1 分钟（根据服务器实际情况调整）

脚本内容：

```
pgrep -x mysqld &> /dev/null
if [ $? -ne 0 ];then
bash /www/server/panel/script/rememory.sh
/etc/init.d/mysqld start
fi
```

### 4.2 安装 MySQL 5.7 失败

报错时执行：

```
dnf --enablerepo=crb install libtirpc-devel -y
```
