🚀 Nginx Proxy Manager 一键部署

复制粘贴即用 | Docker Compose v2 | 自动化配置

📖 简介

Nginx Proxy Manager（NPM）是一个网络代理管理工具，可以：

  • 🌐 在一台服务器上管理多个网站
  • 🔒 自动申请和续期 SSL 证书
  • ⚙️ 反向代理内部应用程序
  • 📊 通过网页界面管理所有配置

本教程提供一个完整脚本，一键部署 NPM、MariaDB 和 proxy 网络。

🔍 前置条件

1

检查系统

支持的系统：Ubuntu 18.04+、Debian 10+、CentOS 7+ 等 Linux 系统

cat /etc/os-release
2

检查 root 权限

id -u

输出 0 表示是 root。否则用 sudo -i 切换。

3

检查磁盘空间

df -h /

确保可用空间 > 5GB

🎯 安装步骤

1

创建目录并进入

mkdir -p /opt/npm && cd /opt/npm
2

创建部署脚本

cat > /opt/npm/npm.sh << 'SCRIPT_EOF' #!/usr/bin/env bash set -u -o pipefail [[ "${DEBUG:-0}" == "1" ]] && set -x ROOT_DIR="$(dirname "$(readlink -f "${0:-$PWD/npm.sh}")")" COMPOSE_FILE="$ROOT_DIR/docker-compose.yml" ENV_FILE="$ROOT_DIR/.env" _san_raw="$(basename "$ROOT_DIR" | tr -c 'a-zA-Z0-9-' '_' )" if [[ -z "$_san_raw" ]]; then PROJECT_NAME="npm" else first="${_san_raw:0:1}" [[ "$first" =~ [A-Za-z0-9] ]] && PROJECT_NAME="$_san_raw" || PROJECT_NAME="p$_san_raw" fi export COMPOSE_PROJECT_NAME="$PROJECT_NAME" G='\033[0;32m'; Y='\033[1;33m'; R='\033[0;31m'; B='\033[34m'; NC='\033[0m' say(){ echo -e "${B}ℹ️ $*${NC}"; } ok(){ echo -e "${G}✅ $*${NC}"; } wrn(){ echo -e "${Y}⚠️ $*${NC}"; } die(){ echo -e "${R}❌ $*${NC}"; exit 1; } have(){ command -v "${1:-}" >/dev/null 2>&1; } ensure_root(){ [[ ${EUID:-$(id -u)} -eq 0 ]] || die "需要 root：sudo $0"; } rand_b64(){ head -c 24 /dev/urandom | base64; } detect_ip(){ curl -fsS --max-time 2 ifconfig.me 2>/dev/null && return 0 hostname -I 2>/dev/null | awk '{print $1}' && return 0 echo 127.0.0.1 } detect_tz(){ cat /etc/timezone 2>/dev/null && return 0 echo UTC } compose(){ docker compose --env-file "$ENV_FILE" -f "$COMPOSE_FILE" "$@" } declare -A DEFAULT_PORTS=( [NPM_ADMIN_PORT]=40002 [NPM_HTTP_PORT]=80 [NPM_HTTPS_PORT]=443 ) fixlf(){ find "$ROOT_DIR" -maxdepth 1 -type f \( -name "*.sh" -o -name "*.yml" -o -name ".env*" \) \ -exec sed -i '1s/^\xEF\xBB\xBF//; s/\r$//' {} \; 2>/dev/null || true } install_docker_if_missing(){ if ! have docker; then say "安装 Docker..." apt-get update -y && apt-get install -y docker.io docker-compose-plugin || true systemctl enable --now docker || true fi docker compose version >/dev/null 2>&1 || die "需要 Docker Compose v2" } create_env(){ if [[ ! -s "$ENV_FILE" ]]; then say "生成 .env 文件..." cat > "$ENV_FILE" << ENVEOF PUBLIC_IP=$(detect_ip) TZ=$(detect_tz) NPM_HTTP_PORT=${DEFAULT_PORTS[NPM_HTTP_PORT]} NPM_HTTPS_PORT=${DEFAULT_PORTS[NPM_HTTPS_PORT]} NPM_ADMIN_PORT=${DEFAULT_PORTS[NPM_ADMIN_PORT]} MYSQL_ROOT_PASSWORD=$(rand_b64) MYSQL_PASSWORD=$(rand_b64) MYSQL_DATABASE=npm MYSQL_USER=npm TAG_NPM=latest TAG_MARIADB=10.11 ENVEOF chmod 600 "$ENV_FILE" ok ".env 已生成" else ok ".env 已存在" fi } load_env(){ set -o allexport # shellcheck disable=SC1090 source "$ENV_FILE" set +o allexport } create_compose(){ say "生成 docker-compose.yml..." cat > "$COMPOSE_FILE" << 'YAMLEOF' services: npm-app: image: jc21/nginx-proxy-manager:${TAG_NPM} restart: unless-stopped ports: - "${NPM_HTTP_PORT}:80" - "${NPM_HTTPS_PORT}:443" - "${NPM_ADMIN_PORT}:81" environment: DB_MYSQL_HOST: "npm-db" DB_MYSQL_PORT: 3306 DB_MYSQL_USER: "${MYSQL_USER}" DB_MYSQL_PASSWORD: "${MYSQL_PASSWORD}" DB_MYSQL_NAME: "${MYSQL_DATABASE}" TZ: "${TZ}" volumes: - ./npm_data:/data - ./npm_letsencrypt:/etc/letsencrypt depends_on: npm-db: condition: service_healthy networks: - npm_internal - proxy npm-db: image: mariadb:${TAG_MARIADB} restart: unless-stopped environment: MYSQL_ROOT_PASSWORD: "${MYSQL_ROOT_PASSWORD}" MYSQL_DATABASE: "${MYSQL_DATABASE}" MYSQL_USER: "${MYSQL_USER}" MYSQL_PASSWORD: "${MYSQL_PASSWORD}" TZ: "${TZ}" volumes: - ./npm_db:/var/lib/mysql networks: - npm_internal healthcheck: test: ["CMD", "mysqladmin", "ping", "-h", "localhost"] interval: 10s timeout: 5s retries: 10 networks: npm_internal: driver: bridge proxy: external: true YAMLEOF ok "docker-compose.yml 已生成" } ensure_proxy_network(){ if docker network inspect proxy >/dev/null 2>&1; then ok "已存在外部网络：proxy" else say "创建外部网络：proxy" docker network create proxy >/dev/null 2>&1 || true fi } do_up(){ ensure_root install_docker_if_missing mkdir -p "$ROOT_DIR"/{npm_data,npm_letsencrypt,npm_db} create_env load_env fixlf create_compose ensure_proxy_network say "拉取镜像..." compose pull || true say "启动服务..." compose up -d set -o allexport source "$ENV_FILE" set +o allexport echo echo "================= 🚀 部署完成 🚀 =================" echo "NPM 管理面板: http://${PUBLIC_IP}:${NPM_ADMIN_PORT}" echo "HTTP 端口: ${NPM_HTTP_PORT} HTTPS 端口: ${NPM_HTTPS_PORT}" echo "默认账户: admin@example.com / changeme" echo "==================================================" compose ps || true } do_down(){ ensure_root compose down --remove-orphans ok "已停止（数据已保留）" } do_logs(){ ensure_root compose logs -f --tail=200 "${@:-}" } do_status(){ ensure_root compose ps "${@:-}" } main(){ case "${1:-up}" in up) do_up ;; down) do_down ;; logs) shift || true; do_logs "$@" ;; status) shift || true; do_status "$@" ;; *) echo "用法：$0 [up|down|logs|status]"; exit 1 ;; esac } main "$@" SCRIPT_EOF chmod +x /opt/npm/npm.sh

脚本会自动安装 Docker、生成配置、创建网络并启动服务。

🌐 网络管理

NPM 创建了一个外部 proxy 网络，其他容器可以连接到它，这样 NPM 就可以代理这些容器的流量。

1

查看所有网络

docker network ls
2

将已存在的容器连接到 proxy 网络

如果你已经有一个运行中的容器（例如 mytest），想让 NPM 代理它：

docker network connect proxy mytest

示例： 连接名为 myapp 的容器

docker network connect proxy myapp
3

将容器从网络断开

docker network disconnect proxy mytest
4

查看网络中的容器

docker network inspect proxy

显示所有连接到 proxy 网络的容器及其 IP 地址。

5

在 NPM 中配置代理

容器连接到 proxy 网络后，在 NPM 管理面板中配置：

  1. 访问 NPM：http://YOUR_SERVER_IP:40002
  2. 登录后点击 "Proxy Hosts" → "Add Proxy Host"
  3. 填写：
    • Domain Names： 你的域名（例如 myapp.example.com）
    • Scheme： http 或 https
    • Forward Hostname / IP： 容器名称（例如 myapp）
    • Forward Port： 容器内部端口（例如 8080）
  4. 点击 "Save" 保存

🚨 故障排查

1

容器无法启动

查看日志：

cd /opt/npm && docker compose logs --tail=50

常见原因：

  • 端口被占用：sudo netstat -tulpn | grep -E ':(80|443|40002)'
  • 磁盘空间不足：df -h
  • Docker 未运行：sudo systemctl restart docker
2

无法访问管理面板

检查步骤：

# 检查容器状态 cd /opt/npm && docker compose ps # 检查端口监听 sudo netstat -tulpn | grep 40002 # 检查防火墙 sudo ufw status # 开放端口 sudo ufw allow 80/tcp && sudo ufw allow 443/tcp && sudo ufw allow 40002/tcp
3

数据库连接失败

# 查看数据库日志 cd /opt/npm && docker compose logs npm-db | tail -30 # 重启数据库 docker compose restart npm-db # 如果需要重新初始化（会删除数据） docker compose down && rm -rf npm_db && docker compose up -d
4

proxy 网络不存在

# 手动创建网络 docker network create proxy # 重启 NPM cd /opt/npm && docker compose up -d
5

容器之间无法通信

# 进入 NPM 容器测试 docker exec -it npm-app bash ping myapp # 确保容器连接到 proxy 网络 docker network inspect proxy # 如果未连接，手动连接 docker network connect proxy myapp # 重启容器 docker restart myapp

🔐 安全建议

⚠️ 重要提示
  • 首次登录后立即修改管理员密码
  • 不要将 40002 端口暴露到公网，使用防火墙限制访问
  • 定期备份 /opt/npm/npm_data 和 /opt/npm/npm_db
  • 定期更新镜像：docker compose pull
  • 定期检查日志发现异常
1

创建备份脚本

cat > /opt/npm/backup.sh << 'BACKUP_EOF' #!/bin/bash BACKUP_DIR="/opt/npm/backups" TIMESTAMP=$(date +%Y%m%d_%H%M%S) mkdir -p "$BACKUP_DIR" tar -czf "$BACKUP_DIR/npm_backup_$TIMESTAMP.tar.gz" \ -C /opt/npm npm_data npm_db npm_letsencrypt .env echo "✅ 备份完成: $BACKUP_DIR/npm_backup_$TIMESTAMP.tar.gz" BACKUP_EOF chmod +x /opt/npm/backup.sh

运行备份：/opt/npm/backup.sh

2

恢复备份

cd /opt/npm && tar -xzf backups/npm_backup_YYYYMMDD_HHMMSS.tar.gz && docker compose up -d

🗑️ 清理和回滚

1

停止服务（保留数据）

cd /opt/npm && bash npm.sh down
2

完全卸载（删除所有数据）

cd /opt/npm && docker compose down -v && rm -rf /opt/npm

⚠️ 警告： 此命令会删除所有数据，无法恢复。

3

删除 proxy 网络

docker network rm proxy

注意： 如果有容器连接到此网络，删除会失败。

❓ 常见问题

Q: 脚本需要 root 权限吗？

A: 是的。Docker 操作需要 root 权限。可以用 sudo 运行或切换到 root 用户。

Q: 如何修改管理面板端口？

A: 编辑 /opt/npm/.env，修改 NPM_ADMIN_PORT，然后重启：

cd /opt/npm && sed -i 's/NPM_ADMIN_PORT=40002/NPM_ADMIN_PORT=YOUR_PORT/' .env && docker compose restart npm-app

Q: 如何升级 NPM 版本？

A: 编辑 /opt/npm/.env，修改 TAG_NPM，然后重新拉取并重启：

cd /opt/npm && sed -i 's/TAG_NPM=latest/TAG_NPM=2.x.x/' .env && docker compose pull && docker compose up -d

Q: 如何连接外部数据库？

A: 编辑 docker-compose.yml，修改 NPM 的 DB_MYSQL_* 环境变量，删除 npm-db 服务，然后重启。

Q: 脚本支持哪些操作系统？

A: 所有 Linux 系统，包括 Ubuntu 18.04+、Debian 10+、CentOS 7+ 等。
